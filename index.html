Dados e privacidade

Esta versão salva os orçamentos no armazenamento local do navegador. Eles não são sincronizados entre computadores, não possuem login e podem ser apagados se os dados do navegador forem limpos. Use somente informações fictícias nesta demonstração.

Próxima etapa do produto

Antes de vender assinaturas, será necessário implementar autenticação, banco de dados seguro, separação dos dados de cada empresa, cópias de segurança e uma política de privacidade adequada.
